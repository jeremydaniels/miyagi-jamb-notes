## Acronyms of the World Wide Web

**Objective i: Give full meanings of www, HTTP, HTTPS, HTML, XML**
**Content a: Definition and full meanings of acronyms**

You must know the exact full meanings of these common web acronyms:

- **WWW**: World Wide Web.
- **HTTP**: Hypertext Transfer Protocol.
- **HTTPS**: Hypertext Transfer Protocol Secure.
- **HTML**: Hypertext Markup Language (the standard language used to create web pages).
- **XML**: eXtensible Markup Language (a language used to store and transport data on the web).

## History of the World Wide Web

**Objective ii: Explain the history behind www**
**Content b: Brief history of WWW**

The World Wide Web was invented in **1989** by **Sir Tim Berners-Lee**, a British computer scientist working at **CERN** (the European Organization for Nuclear Research) in Switzerland. 

At the time, scientists from different universities around the world were coming to CERN, but they had trouble sharing information because they used different computers and different software. Berners-Lee wanted to solve this by creating a universal system of linked documents.

- In **1990**, he developed the three foundational technologies of the Web: HTML, URI (URL), and HTTP. He also wrote the very first **web browser** (called WorldWideWeb) and set up the first **web server**.
- In **1991**, the World Wide Web became publicly available to people outside of CERN.
- In **1993**, CERN announced that the Web's technology would be **free for anyone to use** without paying royalties. This decision caused the Web to grow globally at an explosive rate.

**Important distinction:** The World Wide Web is **not** the same thing as the Internet. 
- The **Internet** is the physical, global network of connected computers and cables (the "roads"). 
- The **World Wide Web** is a collection of linked documents that you access *using* the Internet (the "shops and houses" connected by the roads).

## Basic terminologies

**Objective iii: Explain basic terminologies: www, Website, Webpage, Homepage, Protocol etc.**
**Content c: Basic terminologies**

- **WWW (World Wide Web):** A global information system consisting of documents, images, and other media linked together over the Internet.
- **Website:** A collection of related webpages hosted under a single domain name (for example, `waecdirect.org`). If the Web is a massive library, a website is a single book.
- **Webpage:** A single document on a website, usually written in HTML. It can contain text, images, videos, and links. It is like a single page inside a book.
- **Homepage:** The main, starting, or front page of a website. When you type a domain name into a browser without specifying a specific page, it loads the homepage first.
- **URL (Uniform Resource Locator):** The unique web address of a specific webpage (e.g., `https://www.google.com`).
- **Hyperlink (or Link):** A clickable word, phrase, or image that takes the user to another webpage or to another part of the same page.

## Web Protocols

**Objective iv: Define Protocol and list different types of protocols (http, https, ftp, etc.)**
**Content d: Protocols**

A **protocol** is an agreed-upon set of rules and standards that determines how computers communicate with each other across a network. Without protocols, devices would not understand the data they receive from one another.

Common protocols used on the Web and the Internet include:

- **HTTP (Hypertext Transfer Protocol):** The standard rule used by web browsers to request web pages from web servers, and for servers to send those pages back. Data sent by standard HTTP is in plain text and is not secure.
- **HTTPS (Hypertext Transfer Protocol Secure):** The secure version of HTTP. It encrypts the data being sent so that hackers cannot read it. It is essential for banking, passwords, and shopping online. Browsers usually show a padlock icon for HTTPS sites.
- **FTP (File Transfer Protocol):** A protocol used specifically for uploading files from a local computer to a server, or downloading files from a server to a computer.
- **SMTP (Simple Mail Transfer Protocol):** The protocol used for sending electronic mail (email).
- **TCP/IP (Transmission Control Protocol / Internet Protocol):** The fundamental suite of rules that allows the entire Internet to function, ensuring data packets reach the correct destination.

## Advantages and disadvantages of the World Wide Web

**Content e: Advantages and disadvantages of www.**

The Web has transformed society, but it brings both benefits and dangers.

### Uses and benefits of the WWW

**Objective v: List uses and benefits of www.**

- **Global accessibility:** Web pages are accessible from anywhere around the globe, as long as there is an Internet connection.
- **Access to information:** It makes vast amounts of information accessible to the world. You have unlimited access to research, news, and tutorials.
- **Social connection:** You can connect to people from anywhere, keeping in touch with friends and family from home.
- **E-commerce:** You can purchase products online anywhere in the comfort of your home (using platforms like Jumia, Konga, or Amazon).
- **Business growth:** You can create a website for your business and reach millions of customers, doing much more than a physical office can.
- **Instant communication:** It allows you to communicate with anyone around the world through texts, chats, and emails.
- **E-learning:** Online courses and degrees can be completed using the WWW without ever visiting a physical classroom.
- **Online marketing:** Businesses can advertise cheaply and build their branding globally.
- **Professional networking:** It facilitates establishing professional contacts (for example, through LinkedIn).

### Disadvantages of the WWW

**Objective vi: List disadvantages of www**

- **Risk of data and identity theft:** Cybercriminals can steal personal information, passwords, and bank details to impersonate people or steal money.
- **Cyberbullying:** People can use social media and forums to harass, insult, or threaten others online anonymously.
- **Easy spread of fake news:** False information, rumours, and unverified stories can spread rapidly, misleading the public.
- **Hacking:** Unauthorized users can break into websites or web servers to destroy data or disrupt services.
- **Spam mails:** Unsolicited, annoying, or fraudulent junk messages clutter inboxes and often contain harmful links.
- **Exposure to online predators (paedophiles):** The anonymity of the web can allow child predators to use chat rooms and social media to target and exploit young people. 

## Navigating through websites

**Objective vii: Navigate through websites.**
**Content f: Navigation through websites**

Navigating (or "surfing") the web involves moving from one webpage to another. To do this, you use a software application called a **web browser** (such as Google Chrome, Mozilla Firefox, or Microsoft Edge).

**Steps for navigation:**
1. Open your web browser.
2. Click on the **Address bar** at the top of the browser window.
3. Type the **URL** (website address) of the site you want to visit and press the `Enter` key.
4. The browser fetches the homepage. You can read the content, scroll down, or click on **hyperlinks** to visit other pages.
5. You can use the browser's **Back** arrow to return to the previous page, or the **Forward** arrow to go forward again.

**Examples of website navigation listed in the syllabus:**
- **`www.jamb.org.ng`**: The portal for the Joint Admissions and Matriculation Board.
- **`www.waec.org.ng`**: The portal for the West African Examinations Council.
- **`www.neco.org.ng`**: The portal for the National Examinations Council.
- **`www.ui.edu.ng`**: The official website of the University of Ibadan (an educational institution).
- **`www.jgiyc.com`**: An example of a commercial domain.
- **`www.google.com`**: A search engine used to navigate to other websites by searching for keywords.

## Software for web development

**Objective viii: Use of software for web development**
**Content g: Software for web development**

Building websites requires special software tools. Some are simple code editors, while others allow you to design visually by dragging and dropping elements. The syllabus expects you to recognise the following web development tools:

- **FrontPage:** Microsoft FrontPage was a very popular early "WYSIWYG" (What You See Is What You Get) web editor that allowed users to build websites without writing code. It was discontinued many years ago, but remains a classic example in exams.
- **WordPress:** A highly popular Content Management System (CMS) that currently powers a massive percentage of websites on the Internet. It allows users to build, manage, and update websites easily using templates.
- **Dreamweaver:** Adobe Dreamweaver is a professional web design software that allows developers to write code (HTML, CSS) and see a visual preview of their website at the same time.
- **Photoshop:** Adobe Photoshop is fundamentally a graphics and image editing package. However, web developers use it heavily to design the visual layout, buttons, and background graphics of a website before writing the code to build it.
- **Google Web Designer:** A program used to create interactive, animated web content and advertisements using HTML5 code.

## Differences between email and website

**Objective ix: Differentiate between email and website**
**Content h: Differences between email and website**

An email address and a website address are both used on the Internet, but they serve entirely different purposes and have different formats. 

You must be able to tell them apart instantly. The syllabus contrasts the examples `xyz@jamb.gov.ng` and `www.jamb.org.ng`.

- **`xyz@jamb.gov.ng` (Email Address):**
  - **Purpose:** Used for sending and receiving private, electronic messages.
  - **Format:** It always contains the **`@`** (at) symbol. 
  - **Structure:** The part before the `@` (`xyz`) is the user's personal mailbox name. The part after (`jamb.gov.ng`) is the domain name of the mail server.

- **`www.jamb.org.ng` (Website Address / URL):**
  - **Purpose:** Used to access public web pages on a browser.
  - **Format:** It usually starts with **`www`** (World Wide Web) and **never** contains an `@` symbol.
  - **Structure:** It consists of the web prefix (`www`) and the domain name (`jamb.org.ng`).

| Feature | Email Address | Website Address (URL) |
| :--- | :--- | :--- |
| **Main purpose** | Exchanging messages between specific people | Displaying pages of information for the public |
| **Identifying symbol** | Contains the **`@`** symbol | Does **not** contain the `@` symbol |
| **Common prefix** | None | Often starts with **`www.`** |
| **Software used** | Email clients (e.g., Outlook) or webmail | Web browsers (e.g., Chrome, Edge) |
| **Protocols used** | SMTP, IMAP, POP3 | HTTP, HTTPS |
| **Syllabus Example** | `xyz@jamb.gov.ng` | `www.jamb.org.ng` |

## Exam tips and common mistakes

- **Do not confuse the Internet with the WWW.** The Internet is the physical network of computers. The WWW is the collection of web pages you access *through* the Internet.
- **Distinguish HTTP from HTTPS.** Remember that the "S" stands for Secure. If a question mentions secure banking or encryption, the answer is HTTPS.
- **Spotting emails vs URLs.** If a text contains an `@` symbol, it is an email address. If it starts with `www` and has no `@`, it is a website address.
- **FrontPage and Dreamweaver are web development software.** Even though FrontPage is old, do not mistake it for a spreadsheet or database package; it is for creating web pages.
- **FTP is strictly for files.** If a question asks for the protocol used to upload or download a file to a server, the answer is FTP, not HTTP.
- Remember the name **Tim Berners-Lee** as the inventor of the World Wide Web.

## Quick summary

1. The World Wide Web (WWW) is a system of interconnected documents accessed via the Internet, invented by Tim Berners-Lee in 1989.
2. A website is a collection of related web pages, and the homepage is its starting point.
3. A protocol is a set of rules for communication. HTTP and HTTPS are used for web pages, while FTP is used for transferring files.
4. HTML is the standard markup language used to create web pages.
5. The web offers great benefits like e-learning, e-commerce, and global communication, but also brings risks like cyberbullying, hacking, and identity theft.
6. Web browsers (like Chrome and Edge) are software used to navigate through websites using URLs and hyperlinks.
7. Software packages used for web development include WordPress, Dreamweaver, FrontPage, and Google Web Designer.
8. Email addresses always contain an "@" symbol (e.g., `xyz@jamb.gov.ng`), while website URLs usually start with `www` (e.g., `www.jamb.org.ng`).

## Practice questions

**1. What does the acronym HTTP stand for?**

- A. Hypertext Transfer Protocol
- B. Hyperlink Transfer Protocol
- C. Hypertext Transmission Process
- D. Hyperlink Text Protocol

**Answer: A.** HTTP stands for Hypertext Transfer Protocol. It is the rule used by browsers and servers to exchange web pages.

**2. Who is credited with inventing the World Wide Web?**

- A. Bill Gates
- B. Charles Babbage
- C. Tim Berners-Lee
- D. Mark Zuckerberg

**Answer: C.** Tim Berners-Lee invented the World Wide Web in 1989 while working at CERN. Babbage invented early mechanical computers, and Gates founded Microsoft.

**3. Which of the following is a key difference between an email address and a website URL?**

- A. A URL is used for sending private messages, while an email address is public.
- B. An email address always contains the "@" symbol, while a URL does not.
- C. A URL requires a password, but an email address does not.
- D. An email address always begins with "www", while a URL does not.

**Answer: B.** The "@" symbol separates the user from the domain in an email address. Website URLs (like `www.jamb.org.ng`) do not use this symbol.

**4. The first page that loads when you visit a website's domain name is called the:**

- A. Webpage
- B. Protocol page
- C. Hyperlink
- D. Homepage

**Answer: D.** The homepage is the main, starting, or front page of a website. 

**5. Which protocol should be used to ensure that passwords and credit card details are encrypted when browsing a website?**

- A. HTTP
- B. FTP
- C. HTTPS
- D. XML

**Answer: C.** HTTPS (Hypertext Transfer Protocol Secure) encrypts data to keep sensitive information safe from hackers. HTTP does not encrypt data.

**6. A clickable word, phrase, or image that takes a user to another webpage is known as a:**

- A. Protocol
- B. Hyperlink
- C. Web browser
- D. Domain

**Answer: B.** A hyperlink is used to navigate or jump between web pages or different parts of a website.

**7. Which of the following software is historically known as a web development and design package?**

- A. Microsoft Excel
- B. Microsoft FrontPage
- C. CorelDraw
- D. Microsoft Access

**Answer: B.** Microsoft FrontPage is a discontinued WYSIWYG editor used for web development. Excel is a spreadsheet, Access is a database, and CorelDraw is a graphics package.

**8. In the email address `xyz@jamb.gov.ng`, what does `xyz` represent?**

- A. The protocol
- B. The domain name
- C. The user's mailbox name
- D. The web server

**Answer: C.** In an email address, the part before the "@" symbol is the user's specific username or mailbox name, while the part after is the domain name.

**9. Which of the following is considered a primary disadvantage of the World Wide Web?**

- A. Access to online courses and e-learning
- B. The ability to establish professional contacts
- C. The risk of data and identity theft
- D. E-commerce convenience

**Answer: C.** Data and identity theft is a major risk (disadvantage) of using the Web. The other options are all advantages or benefits.

**10. The protocol designed specifically for uploading and downloading files between a client computer and a server is:**

- A. FTP
- B. HTTP
- C. SMTP
- D. HTML

**Answer: A.** FTP stands for File Transfer Protocol, which governs the transfer of files across a network. SMTP is for email, and HTML is a markup language, not a protocol.
