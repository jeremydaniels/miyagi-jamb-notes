## Frequency distribution

**Content item (a): frequency distribution.**

When data is collected (for example, the JAMB scores of 50 students), it is usually in a disorganized form called **raw data**. To make sense of it, we organize the data into a **frequency distribution**. 

**Frequency** ($f$) means the number of times a particular value or item occurs in a set of data. A frequency distribution is a table that displays each distinct value or category alongside its frequency. 

### Ungrouped frequency distribution
An ungrouped frequency distribution is used for discrete data where the number of possible values is small. 
For example, if we record the shoe sizes of 15 students as: 38, 39, 38, 40, 42, 39, 39, 41, 38, 40, 39, 42, 40, 39, 41. 

We can use **tally marks** to count them. A tally is a vertical stroke for each count, with every fifth count drawn as a diagonal line across the first four to make a bundle of $5$.

| Shoe Size ($x$) | Frequency ($f$) |
| :---: | :---: |
| 38 | 3 |
| 39 | 5 |
| 40 | 3 |
| 41 | 2 |
| 42 | 2 |
| **Total** | **$\sum f = 15$** |

### Grouped frequency distribution
When the data has a wide range of values (like students' scores out of 100) or is continuous (like heights in cm), listing every single number would make a very long table. Instead, we group the data into **class intervals**. 

For example, marks could be grouped as $10 - 19$, $20 - 29$, $30 - 39$, and so on.

## Identify and interpret frequency distribution tables

**Objective i: identify and interpret frequency distribution tables.**

JAMB often tests your ability to interpret terms related to a grouped frequency distribution table. You must know these five key terms perfectly:

1. **Class interval:** A specific group or range used in the table (for example, $10 - 19$).
2. **Class limits:** The lowest and highest values that can fall into a class interval. For the class $10 - 19$, the **lower limit** is $10$, and the **upper limit** is $19$.
3. **Class boundaries:** These close the gaps between consecutive class intervals so that continuous data has nowhere to hide. 
   - *How to find it:* Find the gap between the upper limit of one class (for example, $19$) and the lower limit of the next class (for example, $20$). The gap is $1$. Divide by $2$ to get $0.5$. 
   - Subtract $0.5$ from the lower limit to get the **lower class boundary** ($10 - 0.5 = 9.5$).
   - Add $0.5$ to the upper limit to get the **upper class boundary** ($19 + 0.5 = 19.5$).
   - The boundaries for the $10 - 19$ class are $9.5 - 19.5$.
4. **Class size (or Class width):** This is the difference between the **upper class boundary** and the **lower class boundary**. 
   - *Common Mistake:* Do not subtract the limits! The width of $10 - 19$ is NOT $19 - 10 = 9$. The correct width is $19.5 - 9.5 = 10$.
5. **Class mark (Mid-point):** The exact middle of a class interval. 
   - It is calculated as $\frac{\text{Lower limit} + \text{Upper limit}}{2}$. 
   - For $10 - 19$, the class mark is $\frac{10 + 19}{2} = \frac{29}{2} = 14.5$.

### Worked Examples

**Example 1**
The table below shows the distribution of ages of people at a seminar. 

| Age (years) | $20 - 24$ | $25 - 29$ | $30 - 34$ | $35 - 39$ |
| :--- | :---: | :---: | :---: | :---: |
| **Frequency** | 6 | 14 | 10 | 5 |

Find:
a) the upper class limit of the third class interval.
b) the class boundaries of the second class interval.
c) the class width.

**Solution**
1. The third class interval is $30 - 34$. The upper limit is the highest value in that interval, which is $34$.
2. The second class interval is $25 - 29$. To find the boundaries, subtract $0.5$ from the lower limit and add $0.5$ to the upper limit.
3. Lower boundary = $25 - 0.5 = 24.5$.
4. Upper boundary = $29 + 0.5 = 29.5$.
5. The class boundaries are $24.5$ to $29.5$.
6. To find the class width, use the boundaries of any interval. Using $25 - 29$:
7. Class width = Upper boundary - Lower boundary.
8. Class width = $29.5 - 24.5 = 5$.

**Example 2**
From the table in Example 1, what percentage of the people are at least $30$ years old?

**Solution**
1. "At least $30$ years old" means ages $30$ and above. This includes the intervals $30 - 34$ and $35 - 39$.
2. Frequency of people $30$ and above = $10 + 5 = 15$.
3. Total frequency = $6 + 14 + 10 + 5 = 35$.
4. Percentage = $\frac{15}{35} \times 100\%$.
5. Simplify the fraction: $\frac{15}{35} = \frac{3}{7}$.
6. $\frac{300}{7}\% \approx 42.86\%$.

## Histogram, bar chart and pie chart

**Content item (b): histogram, bar chart and pie chart.**

Once data is in a frequency table, we can represent it visually using charts. This makes it easier to quickly spot trends, such as the most common item (the mode).

### 1. Bar Chart
A bar chart is used to represent **discrete** or qualitative data (e.g., shoe sizes, days of the week, car colours).
- It consists of rectangular bars drawn on a grid.
- The height (or length) of each bar is directly proportional to its frequency.
- **Crucial feature:** The bars are drawn with **equal gaps** between them because the categories are separate and distinct. All bars must have the same width.

### 2. Histogram
A histogram looks similar to a bar chart but is used for **grouped continuous data**.
- Because the data is continuous, there are **no gaps** between the bars. The bars touch each other.
- The horizontal $x$-axis represents the **class boundaries** (not the limits). 
- The vertical $y$-axis represents the frequency.
- The area of each bar is proportional to its frequency. Since the class widths are normally equal in UTME questions, the height of the bar represents the frequency.

### 3. Pie Chart
A pie chart is a circular graph divided into sectors, resembling slices of a pie.
- The total circle represents the total frequency, which corresponds to $360^\circ$.
- Each sector represents a category, and the angle of the sector at the center is proportional to the frequency of that category.

## Interpret information on histogram, bar chart and pie chart

**Objective ii: interpret information on histogram, bar chart and pie chart.**

### Interpreting Bar Charts

[IMAGE: A clean flat textbook style bar chart. The title is "Number of cars sold per day". The y-axis is labeled "Frequency (Number of cars)" with scale 0, 2, 4, 6, 8, 10. The x-axis is labeled "Days of the Week" with discrete categories: Monday, Tuesday, Wednesday, Thursday, Friday. There are equal gaps between the bars. The bar heights are: Monday (4), Tuesday (6), Wednesday (3), Thursday (8), Friday (5). The bars are a uniform solid light blue colour. White background.]

To interpret a bar chart, simply read the category on the $x$-axis and trace the top of the bar across to the $y$-axis to find its frequency.

**Worked Example 3**
Using the description of the bar chart above:
How many more cars were sold on Thursday than on Monday and Wednesday combined?

**Solution**
1. From the chart, cars sold on Thursday = $8$.
2. Cars sold on Monday = $4$.
3. Cars sold on Wednesday = $3$.
4. Combined sales for Monday and Wednesday = $4 + 3 = 7$.
5. Difference = $8 - 7 = 1$.

### Interpreting Histograms and Finding the Mode

[IMAGE: A clean flat textbook style histogram. The title is "Heights of students". The y-axis is labeled "Frequency" with scale 0, 5, 10, 15, 20. The x-axis is labeled "Height (cm)" with continuous numbers: 149.5, 159.5, 169.5, 179.5, 189.5. The bars touch each other with no gaps. The bar heights are: 149.5-159.5 (5), 159.5-169.5 (15), 169.5-179.5 (20), 179.5-189.5 (10). Dashed lines are drawn inside the tallest bar (169.5-179.5) to estimate the mode: one diagonal line from the top-left corner of the tallest bar to the top-left corner of the next bar (179.5-189.5), and another from the top-right corner of the tallest bar to the top-right corner of the previous bar (159.5-169.5). A vertical dashed line drops from the intersection of these diagonals to the x-axis, pointing to an estimated value of 172.8 cm. White background.]

JAMB frequently tests your ability to **estimate the Mode** from a histogram. The mode is the value with the highest frequency, which corresponds to the tallest bar. 

**Steps to find the mode geometrically from a histogram:**
1. Identify the tallest bar (the modal class).
2. Draw a straight line from the top-left corner of the tallest bar to the top-left corner of the bar immediately to its right.
3. Draw a second straight line from the top-right corner of the tallest bar to the top-right corner of the bar immediately to its left.
4. Locate the point where these two lines intersect.
5. Drop a straight vertical line from this intersection down to the $x$-axis. The value on the $x$-axis is the estimated mode.

**Worked Example 4**
A histogram has boundaries $9.5 - 19.5$, $19.5 - 29.5$, $29.5 - 39.5$ with frequencies $4$, $10$, and $7$ respectively. Which interval contains the mode?

**Solution**
1. The mode always falls within the class with the highest frequency.
2. The frequencies are $4$, $10$, and $7$. The highest frequency is $10$.
3. Therefore, the mode lies in the interval $19.5 - 29.5$.

### Interpreting Pie Charts

[IMAGE: A clean flat textbook style pie chart. The circular chart is divided into sectors. The title is "Monthly Budget". The sectors are labeled with their items and angles: Food ($120^\circ$), Rent ($90^\circ$), Transport ($60^\circ$), Savings ($40^\circ$), and Others ($50^\circ$). The sectors are shaded in different distinct colours. White background.]

The fundamental formula for pie chart calculations is:
$$ \text{Angle of Sector} = \frac{\text{Frequency of the item}}{\text{Total Frequency}} \times 360^\circ $$

If a question asks you to find the frequency (actual number) when given the angle, rearrange the formula:
$$ \text{Frequency} = \frac{\text{Angle of Sector}}{360^\circ} \times \text{Total Frequency} $$

**Important note:** Sometimes, an angle is not written as a number, but marked with a small square box near the center. That square is the universal mathematical symbol for a **right angle**, which means exactly **$90^\circ$**. Furthermore, the sum of all angles around the center of the pie chart must equal $360^\circ$.

**Worked Example 5**
A farmer has $120$ goats, $80$ sheep, $40$ cows, and $60$ pigs. If this data is represented on a pie chart, what is the angle of the sector representing sheep?

**Solution**
1. Find the total number of animals: $120 + 80 + 40 + 60 = 300$.
2. Identify the number of sheep: $80$.
3. Use the formula: $\text{Angle} = \frac{80}{300} \times 360^\circ$.
4. Simplify the fraction: $\frac{80}{300} = \frac{8}{30} = \frac{4}{15}$.
5. Multiply by $360$: $\frac{4}{15} \times 360^\circ = 4 \times 24^\circ = 96^\circ$.

**Worked Example 6**
The pie chart of a student's expenditure shows that she spent $105^\circ$ on textbooks. If her total expenditure was ₦24,000, how much did she spend on textbooks?

**Solution**
1. The angle for textbooks is $105^\circ$.
2. The total amount is ₦24,000, which corresponds to the full circle ($360^\circ$).
3. Amount on textbooks = $\frac{105^\circ}{360^\circ} \times 24,000$.
4. Simplify: $\frac{105}{360} \times 24000 = \frac{105}{36} \times 2400$.
5. Divide $2400$ by $36$: Both divide by $12$ to give $\frac{105}{3} \times 200$.
6. $35 \times 200 = 7,000$. 
7. She spent ₦7,000 on textbooks.

**Worked Example 7**
The grades of students in a JAMB mock exam are shown on a pie chart. The angles are: A ($3x^\circ$), B ($4x^\circ$), C ($x^\circ$), D ($60^\circ$), and F ($2x^\circ$). Find the value of $x$.

**Solution**
1. The sum of angles at the center of a circle is $360^\circ$.
2. Set up the equation: $3x + 4x + x + 60 + 2x = 360$.
3. Add the like terms: $10x + 60 = 360$.
4. Subtract $60$ from both sides: $10x = 300$.
5. Divide by $10$: $x = 30$.

## Key terms

| Term | Meaning |
| --- | --- |
| **Frequency distribution** | A table listing distinct values or intervals alongside the number of times they occur |
| **Class interval** | A specific range into which continuous data is grouped (e.g., $10-19$) |
| **Class limits** | The lowest and highest values that can strictly belong to a class interval |
| **Class boundaries** | Values halfway between the upper limit of one class and the lower limit of the next; they close the gaps between classes |
| **Class mark** | The mid-point of a class interval; calculated as (Lower limit + Upper limit) / 2 |
| **Class width** | The size of a class, calculated by subtracting the lower class boundary from the upper class boundary |
| **Bar chart** | A chart for discrete data using rectangular bars with gaps between them |
| **Histogram** | A chart for continuous data using rectangular bars that touch each other |
| **Pie chart** | A circular chart divided into sectors, where the angle of each sector is proportional to its frequency |

## Exam tips and common mistakes

- **Class width error:** When calculating class width, do NOT subtract the class limits. Always subtract the class boundaries. The width of $20-29$ is $29.5 - 19.5 = 10$, not $9$.
- **Histogram vs Bar chart:** If a question asks which chart is used for continuous grouped data, the answer is a Histogram. If it asks for discrete data with distinct categories, it is a Bar chart.
- **Finding the Mode:** Remember that the Mode can be estimated directly from a histogram by drawing diagonals within the tallest bar. The Median cannot be found this way (it requires a cumulative frequency curve or Ogive).
- **Pie chart right angles:** If you see a square symbol in a pie chart sector, immediately write down $90^\circ$ for it before writing your sum-to-$360^\circ$ equation.
- **Reading Pie chart wording carefully:** Check whether the question is asking for the *angle*, the *frequency (number)*, or the *percentage*. For instance, a $90^\circ$ sector is $\frac{1}{4}$ of the circle, which is $25\%$.

## Quick summary

1. A frequency distribution organizes raw data into a table showing how often each value or group occurs.
2. For grouped data, class limits are the stated start and end numbers, while class boundaries bridge the gap between classes (e.g., $9.5 - 19.5$ for a $10 - 19$ class).
3. Class width is calculated as Upper Boundary minus Lower Boundary.
4. Class mark is the mid-point of an interval: (Lower limit + Upper limit) / $2$.
5. A bar chart has gaps between bars and is used for discrete data.
6. A histogram has no gaps between bars and is used for grouped continuous data. The Mode can be estimated directly from it.
7. A pie chart represents data in a circle of $360^\circ$. The formula is: $\text{Sector Angle} = (\frac{\text{Frequency}}{\text{Total}}) \times 360^\circ$.

## Practice questions

**1. The marks scored by 15 students in a test are: 5, 3, 6, 5, 8, 7, 5, 4, 3, 5, 6, 8, 7, 5, 9. What is the frequency of the mark 5?**

- A. 4
- B. 5
- C. 6
- D. 15

**Answer: B.**
1. Count the number of times the value $x = 5$ appears in the list.
2. The values are: $5, 3, 6, 5, 8, 7, 5, 4, 3, 5, 6, 8, 7, 5, 9$.
3. The value $5$ appears exactly $5$ times (at positions 1st, 4th, 7th, 10th, 14th).
4. Therefore, the frequency is $f = 5$.
The mistake behind option A is missing one of the counts, and option D is the total frequency, $n = 15$.

**2. In a grouped frequency table, the class interval is given as $11 - 15$. What is the lower class boundary?**

- A. 10.0
- B. 10.5
- C. 11.0
- D. 11.5

**Answer: B.**
1. The lower limit is $11$. The preceding class would end at $10$.
2. The gap is $11 - 10 = 1$. The adjustment is $1 / 2 = 0.5$.
3. Lower boundary = Lower limit - $0.5 = 11 - 0.5 = 10.5$.
Option C is the lower class limit, not the boundary.

**3. What is the class width for the class interval $40 - 49$?**

- A. 9
- B. 9.5
- C. 10
- D. 11

**Answer: C.**
1. Lower limit = $40$; Upper limit = $49$.
2. Lower boundary = $40 - 0.5 = 39.5$.
3. Upper boundary = $49 + 0.5 = 49.5$.
4. Class width = Upper boundary - Lower boundary = $49.5 - 39.5 = 10$.
Option A is the common mistake of subtracting the limits directly ($49 - 40$).

**4. A survey shows the following distribution of cars: Toyota 45, Honda 30, Nissan 15, and Ford 30. If represented on a pie chart, what is the angle of the sector for Toyota?**

- A. $45^\circ$
- B. $90^\circ$
- C. $135^\circ$
- D. $150^\circ$

**Answer: C.**
1. Total number of cars = $45 + 30 + 15 + 30 = 120$.
2. Frequency of Toyota = $45$.
3. Angle = $\frac{45}{120} \times 360^\circ$.
4. Simplify: $\frac{45}{1} \times \frac{360}{120} = 45 \times 3 = 135^\circ$.
Option A incorrectly assumes the frequency is the angle.

**5. A sector of a pie chart has an angle of $108^\circ$ and represents 15,000 bags of cement sold. What is the total number of bags sold?**

- A. 40,000
- B. 45,000
- C. 50,000
- D. 60,000

**Answer: C.**
1. Use the formula: $\frac{\text{Angle}}{360^\circ} \times \text{Total} = \text{Frequency}$.
2. $\frac{108}{360} \times \text{Total} = 15,000$.
3. $\text{Total} = 15,000 \times \frac{360}{108}$.
4. Divide $360$ and $108$ by $36$: $\frac{360}{108} = \frac{10}{3}$.
5. $\text{Total} = 15,000 \times \frac{10}{3} = 5,000 \times 10 = 50,000$.
Option B comes from wrong fraction arithmetic.

**6. Which of the following statistics can be estimated directly by drawing intersecting lines within the tallest bar of a histogram?**

- A. Mean
- B. Median
- C. Mode
- D. Range

**Answer: C.**
1. The tallest bar of a histogram represents the highest frequency, $f_{max}$, which defines the modal class.
2. By drawing intersecting diagonals from the top corners of the modal bar to the adjacent bars, we find an intersection point.
3. Dropping a perpendicular from this point to the $x$-axis gives the estimated Mode ($M_o$).
Option B (Median) requires a cumulative frequency curve (Ogive).

**7. In a pie chart, four sectors have angles $x^\circ$, $2x^\circ$, $3x^\circ$, and $90^\circ$. Find the value of $x$.**

- A. 30
- B. 45
- C. 60
- D. 90

**Answer: B.**
1. The sum of angles in a pie chart is $360^\circ$.
2. $x + 2x + 3x + 90 = 360$.
3. $6x + 90 = 360$.
4. $6x = 360 - 90 = 270$.
5. $x = \frac{270}{6} = 45$.
Option A ($30$) happens if the student equates only the unknown angles to $180^\circ$ ($6x = 180$). Option C ($60$) happens if the student forgets the $90^\circ$ ($6x = 360$).

**8. The table below shows the distribution of marks scored by students:**

| Marks | 0-4 | 5-9 | 10-14 | 15-19 | 20-24 |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **Frequency** | 2 | 5 | 8 | 4 | 1 |

**How many students scored at least 10 marks?**

- A. 5
- B. 8
- C. 13
- D. 20

**Answer: C.**
1. "At least $10$ marks" means marks from $10$ upwards.
2. This includes the classes $10-14$, $15-19$, and $20-24$.
3. Frequencies = $8 + 4 + 1$.
4. Sum = $13$.
Option B is only the students in the $10-14$ class.

**9. What is the class mark (mid-point) of the interval $21 - 30$?**

- A. 9
- B. 25
- C. 25.5
- D. 30

**Answer: C.**
1. Class mark = $\frac{\text{Lower limit} + \text{Upper limit}}{2}$.
2. Class mark = $\frac{21 + 30}{2}$.
3. Class mark = $\frac{51}{2} = 25.5$.
Option B ($25$) is a common guess for the "middle" without using the exact formula.

**10. Which of the following is true about a bar chart?**

- A. It is used to represent continuous data.
- B. The bars must touch each other without any gaps.
- C. The width of the bars varies according to the frequency.
- D. It is drawn with equal gaps between the bars.

**Answer: D.**
1. A bar chart represents discrete or categorical data, such as distinct groups $x_1, x_2, x_3$.
2. Because the categories are separate and distinct, the chart is drawn with equal gaps between the bars.
3. The bars must all have the same width $w$; only the height changes according to the frequency $f$.
Options A and B describe a histogram, where class boundaries are continuous (e.g., $10.5 \le x < 20.5$). Option C is false for standard bar charts.
