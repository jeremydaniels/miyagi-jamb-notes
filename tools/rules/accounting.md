## Accounting (JAMB: Principles of Accounts) specific rules (these override the style example wherever they differ)

CORRECTNESS
- LENGTH: the word target is a guide, not a quota. Write as long as the topic needs to cover every content item and objective fully, with no padding and no repetition, and never cut required content to save space.
- SYLLABUS ERRORS THAT AFFECT TEACHING: first teach what JAMB expects (the syllabus wording), then add a short "Note" (a blockquote starting "**Note:**") giving the correct or current position. Hedge anything time-sensitive ("at the time of writing").
- Wherever a file contains a calculation (ledger balances, trial balances, accounting equation, discounts, cash book and bank reconciliation balances, depreciation, provisions, accruals and prepayments, stock valuation, control accounts, missing figures, ratios and percentages, manufacturing cost, subscriptions, departmental and branch profit, joint venture profit, partnership appropriation and goodwill, share issues, company ratios, consolidated revenue fund), you MUST use the code execution tool to verify it before writing it, and check every wrong option of each practice question. A file with no calculations (for example ethics or information technology) does not need the tool. Never state an unverified number. Run the checks silently; do not mention the tool or paste code in the notes.
- SHOW FULL WORKING AS NUMBERED STEPS in every worked example and every practice-question explanation: Step 1, Step 2, and so on, each saying what is done and why, ending with the answer in a sentence. State the formula first and explain each term.
- UNITS: put the unit on every quantity, in the working and in every option. Money is always in naira, written ₦ (for example ₦45,000). Percentages use %, ratios show the form (for example 2 : 1 or 1.5 times), depreciation rates show "% per annum", and time shows months or years. Never leave a bare number where an amount of money is meant.
- All working must be doable by hand with no calculator: use neat numbers. Every trial balance must balance, every statement of financial position must balance and every reconciliation must agree; check this in code before writing it.
- NEVER INVENT FACTS, DATES, LAWS, OR FIGURES. Accounting rules, standards, thresholds and Nigerian institutions change. Describe how things work, name the institutions and their functions, and where a date, law, rate or standard may have changed say "at the time of writing" and tell students not to memorise it. If textbooks differ (stock or inventory, debtors or receivables, creditors or payables, "statement of profit or loss" or "income statement", "statement of financial position" or "balance sheet", "non-current" or "fixed" assets), give both names the first time and say they mean the same.
- Follow the Transcription notes for this subject. In particular: the official JAMB name is "Principles of Accounts"; teach the IASB as JAMB lists it, then add a Note that it is an international standard-setter, not a Nigerian body (the Nigerian standard-setter is the FRCN); teach LIFO fully, then add a Note that LIFO is not allowed under IAS 2 / IFRS; teach goodwill and single column cash books even though they have no matching objective.
- Nigerian bodies and terms (ICAN, ANAN, FRCN, CAC, the Office of the Accountant-General of the Federation, the Auditor-General, TSA, IPPIS, IPSAS, NGX, CBN, FIRS, VAT) may be named and explained by function. Hedge anything that may have changed, such as exact powers, rates, thresholds and the status of a scheme.

FORMAT
- Write ledger accounts, cash books, trial balances, statements and reconciliations as Markdown tables with Dr and Cr columns (or the layout the topic needs), with ₦ in the heading, and give the numbers in every table. Use "Dr" and "Cr" consistently and state the double entry for each transaction in words first (debit what, credit what).
- Write formulas in Markdown/LaTeX (`$...$` inline, `$$...$$` display) and explain every symbol. Never use a bare dollar sign for money. Keep each `$...$` on one line. Use plain text, not LaTeX, in headings.

HOW TO TEACH
- Explain the idea in plain words first, then show one fully worked example with a table, then a second example that looks different (for example a different type of business). Use Nigerian businesses and settings: a provision store in Mushin, a tailor in Aba, a school tuck shop, a cooperative society, a church or an old students' association (for not-for-profit accounts), a bakery in Kano (for manufacturing accounts), a local government treasury.
- Explain every content item, named example and objective fully with its own heading. Use comparison tables wherever the syllabus says differentiate, compare, distinguish or contrast (for example bookkeeping and accounting, trade and cash discount, bad debts and provision for bad debts, SLCA and PLCA, incomplete records and single entry, capital and revenue reserves).
- Add an `[IMAGE: ...]` placeholder wherever a diagram helps (the accounting equation, flow from source document to ledger, a bank reconciliation layout, a manufacturing account layout, the organisation of a branch), with a detailed description including the exact figures, so it can be drawn accurately later.
- Include a "Common mistakes" note in each major section (for example debiting the wrong side, forgetting to reverse an adjustment, mixing up accruals and prepayments, applying depreciation on the wrong base).

PRACTICE QUESTIONS (exactly 10)
- Real JAMB style: short multiple-choice questions like past UTME papers, mixing easy, medium and harder items and covering all objectives of the file (definitions, double entry, statements, and calculations).
- The wrong options must be plausible and each based on a typical misunderstanding or calculation slip (for example adding instead of subtracting an accrual). Only one option may be correct. Every money option carries ₦.
- After "**Answer: X.**" (on the same line) give a clear explanation with numbered working for calculations, then name the mistake behind the most tempting wrong option, and make sure that explanation is TRUE: the option must really come from the mistake you describe.
