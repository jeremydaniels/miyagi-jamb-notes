## Chemistry-specific rules (these override the style example wherever they differ)

CORRECTNESS AND UNITS ARE CRITICAL
- You MUST call the code execution tool BEFORE writing the notes: draft every worked example and the 10 practice questions (with their options), then run Python that recomputes every calculation and answer (moles, masses, concentrations, gas volumes, percentages, rates, enthalpy, Faraday, pH) and checks each wrong option, and that checks every chemical equation you write is balanced for atoms and charge. A file written without a code-tool call is rejected. Never state an unverified number. Run the checks silently; do not mention the tool or paste code in the notes.
- UNITS: every quantity in every worked example, working step, practice question and option MUST show its unit (g, mol, mol dm$^{-3}$, dm$^3$, cm$^3$, kJ mol$^{-1}$, s, K, °C, C, A, and so on). Carry units through the working, check the unit of the final answer, and check conversions (cm$^3$ to dm$^3$, g to kg, °C to K, minutes to seconds). Give the unit of every symbol the first time a formula appears. When an answer has no unit (a ratio, pH, a mole ratio, a percentage) say so.
- Use the constants and atomic masses JAMB normally gives, and state every value you use (for example H = 1, C = 12, N = 14, O = 16, Na = 23, Mg = 24, S = 32, Cl = 35.5, Cu = 64; molar volume 22.4 dm$^3$ mol$^{-1}$ at s.t.p.; Avogadro constant $6.02 \times 10^{23}$ mol$^{-1}$; Faraday 96,500 C mol$^{-1}$). All working must be doable by hand with no calculator: choose neat numbers.
- If a definition, name, classification, colour, observation or number varies between textbooks (for example IUPAC names versus older names, trioxonitrate(V) versus nitrate, s.t.p. conditions, definitions of acids), say so in the text. Never invent facts. For laboratory tests and observations, give the standard textbook result.

FORMAT
- Write chemical formulas with subscripts and charges in Markdown/LaTeX, for example `$\text{H}_2\text{SO}_4$`, `$\text{SO}_4^{2-}$`, and write equations with state symbols, for example `$\text{Zn(s)} + 2\text{HCl(aq)} \rightarrow \text{ZnCl}_2\text{(aq)} + \text{H}_2\text{(g)}$`. Use `$...$` inline and `$$...$$` for display equations. Explain every symbol. Write units in text mode.
- Never use a bare dollar sign for money: write naira as ₦. Do not use `$` except for maths and chemistry. Keep each `$...$` on one line. Use plain text, not LaTeX, in headings.

HOW TO TEACH
- Show full working for every calculation as a NUMBERED LIST, one step per item, saying WHY each step is done (write the equation, balance it, find moles, use the mole ratio, convert, state the answer with its unit). Give at least 3 worked examples per calculation-type objective, from easy to JAMB level, using Nigerian contexts (cassava processing, palm oil, crude oil and the Niger Delta, limestone and cement, water treatment, kerosene, batteries, local salt and soda).
- Explain the theory in words before the formulas. Where the syllabus names a process, element, compound, test, industrial process or example, explain it fully: conditions, equations, observations, uses and hazards where relevant. Use comparison tables where the syllabus says compare, differentiate or distinguish.
- Teach the standard method first, then any JAMB shortcut, and say when it is safe. Include a "Common mistakes" note in each major section (unbalanced equations, wrong formulae, wrong mole ratio, unit slips, confusing oxidation and reduction, wrong names) with the wrong working and the corrected version.
- Add an `[IMAGE: ...]` placeholder wherever a diagram, apparatus set-up, structure, graph or flow chart helps, with a detailed description including the exact items, labels and arrangement, so it can be drawn accurately later.

PRACTICE QUESTIONS (exactly 10)
- Real JAMB style: short multiple-choice questions of the kind in past UTME papers, mixing easy, medium and harder items and covering all objectives of the file, with theory, naming and observation questions as well as calculations. Include the units in the options of calculation questions.
- The wrong options must be plausible and each based on a typical mistake. Only one option may be correct.
- After "**Answer: X.**" (on the same line) show the working as a NUMBERED LIST with units, then name the mistake behind the most tempting wrong option, and make sure that explanation is TRUE: the value in that option must really come from the mistake you describe.
