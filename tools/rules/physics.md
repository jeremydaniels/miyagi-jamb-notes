## Physics-specific rules (these override the style example wherever they differ)

CORRECTNESS AND UNITS ARE CRITICAL
- You MUST call the code execution tool BEFORE writing the notes: draft every worked example and the 10 practice questions (with their options), then run Python that recomputes every calculation and answer and checks each wrong option. A file written without a code-tool call is rejected. Never state an unverified number. Run the checks silently; do not mention the tool or paste code in the notes.
- UNITS: every physical quantity in every worked example, every step of working and every practice question and option MUST show its SI unit (or the unit the question uses). Carry units through the working. Check the units of the final answer (dimensional consistency), prefixes (cm to m, g to kg, minutes to seconds, kPa to Pa) and conversions. Give the unit of every symbol the first time a formula appears. When an answer has no unit (a ratio, a refractive index, an efficiency, a number of fringes) say so.
- Use the values JAMB normally gives, for example $g = 10\ \text{m s}^{-2}$ (say that some textbooks use $9.8\ \text{m s}^{-2}$ and that the question will state which to use), and state every constant you use. All working must be doable by hand with no calculator: choose neat numbers, and leave answers in fraction, surd or $\pi$ form where that is natural. Where JAMB gives tables or constants in the paper, say so.
- If a definition, symbol, sign convention (for example for lenses and mirrors) or classification varies between textbooks, say so in the text.

FORMAT
- Write all formulas in Markdown/LaTeX: `$...$` inline, `$$...$$` on their own lines for display equations, and write units in text mode, for example `$5\ \text{m s}^{-1}$`. Explain every symbol, with its unit, in a short "where ..." list.
- Never use a bare dollar sign for money: write naira as ₦. Do not use `$` except for maths. Keep each `$...$` on one line. Use plain text, not LaTeX, in headings.

HOW TO TEACH
- Show full working for every worked example as a NUMBERED LIST, one step per list item, and say WHY each step is done (write the formula, substitute with units, calculate, state the answer with its unit). Give at least 3 worked examples per calculation-type objective, from easy to JAMB level, using Nigerian contexts where they help (generators and NEPA/power supply, boreholes, okada, markets, harmattan, Lagos distances).
- Teach the standard method first, then any JAMB shortcut, and say when the shortcut is safe. Include a "Common mistakes" note in each major section (wrong units, unit conversions, sign errors, wrong formula, forgetting to square, degrees and radians) with the wrong working and the corrected version.
- Explain concepts in words before formulas. Where the syllabus names an experiment, device, law or example, explain it fully: apparatus, procedure, observations, precautions and conclusion where relevant. Use comparison tables where the syllabus says compare, differentiate or distinguish.
- Add an `[IMAGE: ...]` placeholder wherever a diagram, graph, ray diagram, circuit, force diagram or apparatus helps, with a detailed description including the exact values, labels, directions and shapes, so it can be drawn accurately later.

PRACTICE QUESTIONS (exactly 10)
- Real JAMB style: short multiple-choice questions of the kind in past UTME papers, mixing easy, medium and harder items and covering all objectives of the file, with theory (concept) questions as well as calculations. Include the units in the options of calculation questions.
- The wrong options must be plausible and each based on a typical mistake (wrong unit conversion, using the wrong formula, sign error). Only one option may be correct.
- After "**Answer: X.**" (on the same line) show the working as a NUMBERED LIST with units, then name the mistake behind the most tempting wrong option, and make sure that explanation is TRUE: the value in that option must really come from the mistake you describe.
